# Bitácora de uso de IA — Semana 6

## 1. Objetivo

Utilicé inteligencia artificial como apoyo para comprender y revisar la implementación de componentes de interfaz con HTML y Tailwind CSS.

## 2. Herramientas utilizadas

- ChatGPT: orientación sobre clases de Tailwind CSS, estructura HTML, componentes y solución de errores.
- Tailwind CSS CLI: compilación de los estilos utilizados en la página.

## 3. Prompts utilizados

1. ¿Cómo puedo utilizar Tailwind CSS para organizar una grilla de tarjetas responsive?
2. ¿Cómo puedo implementar efectos hover y estados de foco accesibles en los botones?
3. ¿Cómo puedo crear un menú responsive para dispositivos móviles?
4. ¿Cómo puedo implementar un modal de detalles con HTML y JavaScript?
5. ¿Cómo puedo verificar que Tailwind CSS compile correctamente los estilos?

## 4. Hallazgos y aprendizajes

- Las clases de Tailwind permiten definir estilos directamente en los elementos HTML.
- Las clases responsive permiten adaptar la distribución de las tarjetas al tamaño de la pantalla.
- Los estados `hover` y `focus-visible` mejoran la interacción y la accesibilidad.
- El elemento `dialog` permite crear un modal que puede abrirse con JavaScript.
- Tailwind CSS CLI genera un archivo CSS a partir de los estilos de entrada.

## 5. Verificación

Se revisó la estructura del HTML, la compilación de Tailwind CSS y el funcionamiento del menú y del modal. Las pruebas finales deben confirmarse en el navegador.

## 6. Conclusión

La inteligencia artificial sirvió como apoyo para resolver dudas y comprender mejor la implementación. El código y el resultado deben verificarse personalmente antes de la entrega.
